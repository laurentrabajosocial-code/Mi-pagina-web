# Mi portafolio web

Portafolio personal de Lauren, creado con HTML y Tailwind CSS. Presenta una
introducción personal y una foto de perfil.

## Archivos principales

- `Mi-Portafolio.html`: página principal.
- `src/Foto perfil.jpg`: foto mostrada en la página.
- `src/input.css`: entrada de Tailwind CSS.
- `dist/output.css`: estilos compilados que carga la página.

## Uso

Instala las dependencias y compila los estilos:

```bash
npm install
npm run build
```

Abre `Mi-Portafolio.html` en el navegador. Si cambias clases de Tailwind,
vuelve a ejecutar `npm run build`; para recompilar al guardar, usa `npm run watch`.
